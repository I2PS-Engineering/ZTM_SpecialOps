# ZTM Special Ops 3.1 Stable — Privacy and network data (Build 3.1.2)

The sections below reproduce the corresponding documents supplied with the **verified official 3.1.2 release archives**. For the actual installed package, the included document is authoritative. Platform differences are intentional; I2PS Engineering has not combined or modified the original terms.

## Linux — verbatim release document

# ZTM Special Ops 3.1 Stable — Network and Local Data (Linux)

ZTM Special Ops needs no I2PS account, sends no analytics or telemetry, and never asks for wallet private keys, passwords or recovery phrases.

**Stored locally:** hardware inventory, CPU, memory and temperature samples (when available), the worker ID, pool shares, benchmark configurations and reports, and saved public receiving addresses. Results stay on this computer until you share or delete them.

**Outbound connections:** the mining pool `pool.hashvault.pro:443` over TLS; GitHub, for the official, checksum-verified XMRig release; the Ubuntu package mirrors for dependencies; and official Monero wallet pages, only when you open them.

**Privacy considerations:** the persistent worker ID and the public receiving address are not credentials, but they let the pool correlate sessions. Read reports and logs before sharing them. No network anonymity is claimed.
